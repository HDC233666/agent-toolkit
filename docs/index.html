Agent 工具调用框架

基于 Function Calling 的 Agent 框架：模型自主选择并执行工具，完成「查时间 → 计算 → 写文件 → 读回校验」这类多步任务。 内置 9 个工具（含只读 SQL 与 MCP 外部工具），支持同轮并行调用、写文件前人工审批、最大步数防死循环。

循环长这样

用户提问→模型决策（tool_calls）→执行工具→结果回灌→再决策→生成回答

做了什么

  • 工具层：calculator（AST 白名单，不用 eval）、now、list_files、read_file、write_file（限制在沙箱目录、拦截路径穿越）、http_get、sql_query（只读语句白名单）、以及两个 MCP 工具。
  • 安全：写文件前必须人工审批——后端通过 SSE 把审批卡片推给前端，用户点「允许执行 / 拒绝」，超时 120 秒视为拒绝；工具异常以结构化 JSON 回灌，模型可自行修正重试。
  • MCP：自己实现 stdio JSON-RPC 客户端（initialize / tools/list / tools/call / ping），启动外部 MCP 服务器并把它的工具注入 Agent 工具表。
  • 可观测：每次对话与工具调用落 MySQL（agent_runs / tool_calls），前端可查历史与运行指标；无数据库时降级 JSONL，保证演示可跑。
